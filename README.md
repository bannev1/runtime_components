# Runtime Components

My personal dotfiles for bash, zsh, vim, gdb, and git.

## Contents

- `.bashrc` – bash config
- `.zshrc` – zsh config
- `.vimrc` – vim config
- `.gdbinit` – gdb config
- `.gitconfig` – git config and aliases
- `install.sh` – installs all the above into your home directory

## Usage

```bash
git clone git@github.com:bannev1/runtime-components.git
cd runtime-components
./install.sh
```

Use `./install.sh --dry-run` to preview changes first.
